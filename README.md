# Structura

Structura — локальный набор инструментов для работы с данными, текстом и
повседневными задачами разработчика. Все преобразования выполняются прямо в
браузере: содержимое полей не отправляется на сервер.

## Возможности

### JSON-валидатор

- проверяет JSON во время ввода;
- показывает точную строку и столбец синтаксической ошибки;
- форматирует JSON с отступами или сжимает в одну строку;
- исправляет типичные ошибки: одинарные кавычки, комментарии, ключи без
  кавычек, хвостовые запятые, лишние и недостающие скобки;
- поддерживает быстрое копирование и переход к проблемному символу.

### JSON ↔ PHP array

- преобразует JSON в PHP-массив с коротким синтаксисом `[]`;
- преобразует PHP-массивы обратно в JSON;
- понимает синтаксис `[]` и `array()`;
- поддерживает вложенные и ассоциативные массивы, комментарии и завершающие
  запятые;
- сообщает строку и столбец ошибки PHP-синтаксиса.

### Сравнение текста

- сравнивает два текстовых фрагмента;
- подсвечивает удалённые и добавленные части;
- сохраняет переносы строк;
- показывает количество изменённых символов.

### Генераторы

- UUID v4;
- текущий Unix timestamp в секундах и миллисекундах;
- ISO 8601 datetime;
- криптографически стойкий токен;
- надёжный пароль заданной длины;
- двусторонняя конвертация timestamp ↔ datetime.

### Base64

- кодирование текста в Base64;
- декодирование Base64 в текст;
- поддержка UTF-8, кириллицы и emoji;
- поддержка URL-safe Base64.

### Regex-тестер

- проверка JavaScript-регулярных выражений;
- управление флагами `g`, `i`, `m`, `s`, `u`;
- подсветка всех найденных совпадений;
- отображение ошибок в регулярном выражении.

### URL Cleaner

- удаляет обратные слеши `\` из экранированных URL;
- преобразует строки вида
  `https:/\/\www.example.com/\something` в
  `https://www.example.com/something`;
- позволяет сразу скопировать очищенную ссылку.

## Интерфейс

- тёмная и светлая темы;
- автоматический выбор системной темы при первом открытии;
- сохранение выбранной темы в `localStorage`;
- адаптивная раскладка для компьютеров и мобильных устройств;
- сохранение состояния инструментов при переключении между ними.

## Технологии

- [Vue 3](https://vuejs.org/)
- [Vite](https://vite.dev/)
- JavaScript ES Modules
- CSS без UI-фреймворков
- встроенный тестовый раннер Node.js

Проект не использует внешние API и серверную часть.

## Требования

- Node.js `^22.18.0` или `>=24.12.0`
- npm

## Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите локальный сервер разработки:

```bash
npm run dev
```

После запуска откройте адрес, который Vite выведет в терминале.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запуск проекта в режиме разработки |
| `npm run build` | Создание production-сборки в `dist/` |
| `npm run preview` | Локальный просмотр production-сборки |
| `npm test` | Запуск всех модульных тестов |

## Публикация на GitHub Pages

Проект настроен для публикации по адресу:

`https://guitaristdave.github.io/structura/`

Workflow `.github/workflows/deploy.yml` запускает тесты, собирает приложение и
публикует `dist/` после каждого push в ветку `main`. В настройках репозитория
GitHub необходимо один раз выбрать `Settings → Pages → Source → GitHub Actions`.

## Структура проекта

```text
src/
├── app/
│   └── ToolboxPage.vue
├── features/
│   ├── base64/
│   ├── generators/
│   ├── json/
│   ├── php-array/
│   ├── regex/
│   ├── text-diff/
│   └── url-cleaner/
├── shared/
│   ├── components/
│   ├── composables/
│   └── layout/
├── App.vue
└── main.js
```

Каждый каталог в `features/` содержит компоненты своего инструмента, чистую
логику преобразований и модульные тесты. Общие компоненты, навигация и логика
темы находятся в `shared/`.

## Тестирование

```bash
npm test
```

Тестами покрыты парсинг и восстановление JSON, преобразование PHP-массивов,
сравнение текста, Base64, Regex, генераторы, timestamp-конвертер и очистка URL.

## Приватность

Structura обрабатывает введённые данные исключительно на устройстве
пользователя. Единственное сохраняемое значение — выбранная тема интерфейса.

## Ограничения

- автоматическое восстановление JSON исправляет распространённые
  синтаксические ошибки, но не угадывает неоднозначные значения;
- PHP-конвертер предназначен для литералов массивов и не выполняет PHP-код;
- Regex-тестер использует синтаксис регулярных выражений JavaScript.
